## How to contribute
1. Team lead pushes the shared project files from `TaskFlow_Complete.zip` to `main` first.
2. Clone repository, run `git switch main && git pull origin main`.
3. Create branch: `git switch -c feature/dashboard-module`.
4. Copy the module files from this ZIP to the same relative paths in the repository.
5. Test your feature with the full project.
6. `git add . && git commit -m "Implement Dashboard Analytics module" && git push -u origin feature/dashboard-module`.
7. Open a Pull Request into `main`.

Note: Your ZIP contains only your module code. It needs the shared starter files and the other modules for full integration.
